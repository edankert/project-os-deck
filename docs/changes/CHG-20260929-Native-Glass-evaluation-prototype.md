# Native Glass evaluation prototype

## Summary

An isolated Rust program can load real Deck note exports or deterministic synthetic fixtures and open a native Glass window. It allocates every selected note, draws visible cards with Metal and shaped text, and supplies search, pull, zoom, view switching, fixture reload and a limited native reader. A diagnostic runner records frame, input, resource and provenance data, rejects source changes and keeps invalid runs. An explicit Electron fixture command uses the current production renderer to check placement and omission counts, pin exported cards across store updates, render frozen real note bodies and replay a placed-subset trace diagnostically. The current Electron app remains the production path; this experiment has no comparative performance verdict yet.
