# Walk scenes and handoff at real scale

The evidence for FEAT-0023. Two scripted walks drive scenes and handoff in the real application with a real pointer and keyboard and keep pictures: `desktop/demos/glass-scenes.cjs` and `desktop/demos/glass-handoff.cjs`. The acceptance check is a person's, and this task prepares it without recording a verdict for it.

**Where it stands, 2026-10-02.** The task stays `doing`. Both walks were run in a Linux container on 2026-10-02 at commit `18f5405`, on this repository and on a copy of `your-trainer`. The scenes walk held all 43 of its checks on each, and the handoff walk all 34. Two boxes and one step are open. The walks do not repeat the route by keyboard alone. The frame cadence while a scene is restored was not measured anywhere, and nothing was measured on the Mac. The record is in [[TST-0076-Scenes-And-Handoff-Are-Walked-With-A-Real-Pointer]]. A quoted check below is one of these two walks', as it read on this repository.

**After the second close-out and the independent review, 2026-10-02.** Both walks were changed after the pass the second close-out cited, and every change ran in the pass at `18f5405`. Commit `972985f` added to the scenes walk what that close-out found unchecked: saving under the open scene's own name, a visible focus on each scene button, "dismiss" and "restore" reached with Tab and pressed with Enter, both ends of each header clear while the scene's message is shown, and a retried document whose place can only come from the scene. It made the handoff walk require the chooser's sentence to be drawn whole. Commit `e3f1460` made the handoff walk send one note with keys alone. The fixes for the review added four checks to the scenes walk and one step to the handoff walk, and rewrote one check; [[TST-0076-Scenes-And-Handoff-Are-Walked-With-A-Real-Pointer]] says what each saw. The reviewers ran node suites only and marked both walks *not checked*, in both rounds.
