# Deck opens on the wheel

The wheel becomes a page in Deck. An address with no page opens it, a sector opens its phase, and the pointer and the keyboard both reach every mark.

## Definition of Done
- [ ] `page=wheel` is registered and Deck opens on it.
- [ ] Hover shows a callout, keyboard focus reaches every sector and disc, the list twin is one key away.
- [ ] The served host shows the wheel read-only.
