# DES-0005's plates are drawn for every screen with every mark

## Purpose

DES-0005's plates are generated by the screen code. Codex's review found that dropping three screens from the script, or losing every mark in serialising, passed every test. This suite runs the script into a temporary folder and checks what it wrote.

## Procedure

1. `bash tools/scripts/run-desktop-tests.sh overview-plates`.

## Expected results

- A plate exists for each of the seven screens on Deck and on your-trainer.
- Each SVG plate holds as many ticket marks as its scene.
- Each plate has at most 60 words at rest, and the prototype page is written.
