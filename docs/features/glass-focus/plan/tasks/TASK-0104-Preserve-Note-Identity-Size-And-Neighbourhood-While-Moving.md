# Keep one note and its neighbourhood intact

A note opened in Glass is now drawn once, at the size the person chose, and dragging it carries the cards gathered round it. The repair is committed. An independent review on 2026-10-02 found two defects in it and gaps in its two suites. Those are fixed in the commits merged in `0dc5708`, and the pass at `18f5405` ran the fixes; "Notes" says what they were. One box below is still open, the rendering cost on the Mac, so this task stays `doing`. TST-0052, the walk a person makes, has not been walked.

## Definition of Done

Every count and quotation below is from the pass of 2026-10-02 at `18f5405`, which "Verification" describes.

## Notes

**The review of 2026-10-02 found two defects in what this task built, and both are fixed.** FEAT-0017's "Review" has each finding with its evidence.

- A note with no size of its own changed size when another note was resized. Such a note is drawn at the view's size, and a resize changes the view's size. A card has no size when Spread put the note on the desk, when another window handed it over without one, or when the state file is older than this task. The store now gives each such note the size it is drawn at before the view's size changes (`0d39033`).
- A press and release on the resize corner, with no movement, stored the size the document was drawn at. In a field too small for the document that is the fitted size, so it replaced the size a person chose. A press now stores nothing until it has moved more than 5 pixels, a drag is measured from the size the note has, and Escape during the drag puts the size back (`fb829b0`). Three checks were added to the walk `focus-neighbourhood` for this, and all three held at `18f5405`; "Verification" says what they saw.
