# Native Glass preliminary evidence and open measurements

This is a progress record, not the benchmark report or a migration recommendation. The frozen targets and validity rules are in [BENCHMARK.md](BENCHMARK.md). All raw native records named below are local and ignored by Git under `prototypes/native-glass/local/runs/`; their manifests hold fixture, trace, binary and protocol hashes. The source repository remains unchanged by export and native runs.

The Mac Studio used so far is `Mac14,13`, Apple M2 Max with 32 GiB RAM and a 30-core GPU, macOS 26.5.2. Native runs used Metal and a 1440 × 900 logical window at 60 Hz, but earlier diagnostics landed on both the intended 3440 × 1440 display and a second 1920 × 1080 display. Each raw metrics file identifies its actual monitor. The runner now pins the native window to the 3440 × 1440 display and rejects a wrong-display record. These are frame scheduling and submission measurements, not scanout or physical input-to-photon timings. [BASELINE.md](BASELINE.md) records the separate, provisional production Electron run.
